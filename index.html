Lưu dữ liệu lên GitHub

Dữ liệu lưu thành 1 file JSON trong repo của bạn. Dùng repo private riêng để người khác không đọc được.
Token chỉ lưu trong trình duyệt của máy này. Tạo token: GitHub → Settings → Developer settings → Fine-grained tokens → chọn đúng 1 repo → Contents: Read and write.

Bảo vệ dữ liệu

Dữ liệu được ghi 2 nơi trên máy (localStorage + IndexedDB) kèm bản dự phòng tự động. Nếu xoá dữ liệu trình duyệt hoặc đổi máy thì mất cả hai — hãy bật GitHub hoặc xuất JSON định kỳ.
